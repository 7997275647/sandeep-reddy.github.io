# Sandeep Reddy Modugu's Portfolio

This repository contains the source for my personal portfolio website. It
introduces my work as an embedded systems engineer and presents my professional
experience, selected projects, education, technical skills, and contact details.

The site is built with HTML, CSS, and vanilla JavaScript as a static website.
Its interactive features include project filters, a signal visualization, and
responsive navigation. The page is in [index.html](index.html), with local
visual assets stored in `Images/`.
